## Task 1 & 2: 50 条法规要求及结构化拆解

### 分类 1: Brake (6 条)

---

#### BRK-001 | 制动系统配置

| 字段 | 内容 |
|------|------|
| **Requirement** | 自行车必须配备前轮和后轮制动器，或仅后轮制动器 |
| **Regulation Source** | 16 CFR §1512.5(a) |
| **Mandatory / Optional** | Mandatory |
| **Applicable Product** | Bicycle, Kids Bicycle, E-bike |
| **Trigger Condition** | 所有非 track bicycle / one-of-a-kind bicycle |
| **Evidence Required** | BOM 中包含 brake 组件项；产品照片显示制动器安装 |
| **Risk Level** | Critical |

---

#### BRK-002 | 手刹制动距离

| 字段 | 内容 |
|------|------|
| **Requirement** | 仅配备手刹的自行车，制动距离不得超过 4.57m (15ft)，测试速度按 §1512.18(d)(2)(vi) 等效地面速度 |
| **Regulation Source** | 16 CFR §1512.5(b)(1) |
| **Mandatory / Optional** | Mandatory |
| **Applicable Product** | Bicycle, E-bike |
| **Trigger Condition** | 产品配备手刹 (handbrake) |
| **Evidence Required** | 第三方实验室制动性能测试报告，记录制动距离和测试速度 |
| **Risk Level** | Critical |

---

#### BRK-003 | 手刹握距尺寸

| 字段 | 内容 |
|------|------|
| **Requirement** | 手刹握距 (grip dimension) 在枢轴点至杠杆中点之间不得超过 89mm (3.5in)；人行道自行车 (sidewalk bicycle) 不得超过 76mm (3in) |
| **Regulation Source** | 16 CFR §1512.5(b)(3) |
| **Mandatory / Optional** | Mandatory |
| **Applicable Product** | Bicycle, Kids Bicycle (sidewalk bicycle) |
| **Trigger Condition** | 产品配备手刹 |
| **Evidence Required** | 产品规格书中手刹握距尺寸；实物测量数据 |
| **Risk Level** | Major |

---

#### BRK-004 | 手刹操作力

| 字段 | 内容 |
|------|------|
| **Requirement** | 在距手刹杠杆开口端 25mm (1in) 处施加小于 44.5N (10 lbf) 的力应使刹车片接触制动面 |
| **Regulation Source** | 16 CFR §1512.5(b)(5) |
| **Mandatory / Optional** | Mandatory |
| **Applicable Product** | Bicycle, Kids Bicycle, E-bike |
| **Trigger Condition** | 产品配备手刹 |
| **Evidence Required** | 手刹操作力测试报告 |
| **Risk Level** | Major |

---

#### BRK-005 | 脚刹制动力

| 字段 | 内容 |
|------|------|
| **Requirement** | 脚刹在施加 310N (70 lbf) 踏板力时，制动力不得小于 178N (40 lbf) |
| **Regulation Source** | 16 CFR §1512.5(c) |
| **Mandatory / Optional** | Mandatory |
| **Applicable Product** | Bicycle, Kids Bicycle (sidewalk bicycle with seat height ≥ 560mm) |
| **Trigger Condition** | 产品配备脚刹 (footbrake / coaster brake) |
| **Evidence Required** | 脚刹制动力测试报告 |
| **Risk Level** | Critical |

---

#### BRK-006 | 人行道自行车禁止仅配手刹

| 字段 | 内容 |
|------|------|
| **Requirement** | 人行道自行车 (sidewalk bicycle) 不得仅配备手刹 |
| **Regulation Source** | 16 CFR §1512.5(e)(1) |
| **Mandatory / Optional** | Mandatory |
| **Applicable Product** | Kids Bicycle (sidewalk bicycle: seat height ≤ 635mm/25in) |
| **Trigger Condition** | 产品为 sidewalk bicycle (座椅最高位置 ≤ 635mm) |
| **Evidence Required** | BOM 中制动系统配置；座椅高度规格 |
| **Risk Level** | Critical |

---

| 字段 | 内容 |

### 分类 3: Bell (1 条)

---

| **Risk Level** | Minor |

### 分类 4: Chain Guard (3 条)

---

#### CHG-001 | 单速自行车链条防护罩

| 字段 | 内容 |
|------|------|
| **Requirement** | 单前链轮+单后链轮的自行车必须配备链条防护罩，覆盖链条上股及链轮接触区域至少 90° 周长，向后延伸至后轴中心线前方至少 8cm (3.2in) |
| **Regulation Source** | 16 CFR §1512.9(a) |
| **Mandatory / Optional** | Mandatory |
| **Applicable Product** | Bicycle, Kids Bicycle, E-bike (单速) |
| **Trigger Condition** | 产品为单前链轮+单后链轮配置 |
| **Evidence Required** | BOM 中包含 chain guard 组件；产品图纸显示覆盖范围 |
| **Risk Level** | Major |

---

#### CHG-002 | 链条防护罩防夹入测试

| 字段 | 内容 |
|------|------|
| **Requirement** | 链条防护罩必须防止直径 9.4mm (3/8in)、长 76mm (3in) 的测试杆从链条侧以任何方向在 45° 范围内被夹入链条与链轮之间 |
| **Regulation Source** | 16 CFR §1512.9(a) |
| **Mandatory / Optional** | Mandatory |
| **Applicable Product** | Bicycle, Kids Bicycle, E-bike (单速) |
| **Trigger Condition** | 产品为单前链轮+单后链轮配置 |
| **Evidence Required** | 链条防护罩防夹入测试报告；产品图纸标注间隙尺寸 |
| **Risk Level** | Major |

---

#### CHG-003 | 变速器防护

| 字段 | 内容 |
|------|------|
| **Requirement** | 变速器 (derailleur) 必须设有防护装置，防止链条因不当调整或损坏而干扰或阻止车轮旋转 |
| **Regulation Source** | 16 CFR §1512.9(b) |
| **Mandatory / Optional** | Mandatory |
| **Applicable Product** | Bicycle, E-bike (多速/变速) |
| **Trigger Condition** | 产品配备 derailleur 变速系统 |
| **Evidence Required** | BOM 中包含 derailleur guard；产品照片显示防护装置 |
| **Risk Level** | Major |

| **Evidence Required** | 产品照片显示车架永久标签；标签内容样本 |
| **Risk Level** | Major |

---

#### LBL-002 | 车把立管最小插入深度标记

| 字段 | 内容 |
|------|------|
| **Requirement** | 插入式 (quill-type) 车把立管必须包含永久性环形标记或线条，清楚指示最小插入深度；标记距立管最低点不小于立管直径的 2.5 倍 |

#### LBL-003 | 座管最小插入深度标记

### 分类 6: Battery (5 条)

---

#### BAT-001 | 电池过充测试

| 字段 | 内容 |
|------|------|

## Task 4: 法规知识图谱结构

### 4.1 实体类型 (Node Types)

```
┌─────────────────────────────────────────────────────────┐
│                    Entity Types                          │
├──────────────────┬──────────────────────────────────────┤
│ Regulation       │ 法规 (CPSC 1512, CPSIA, UL 2849...) │
│ Section          │ 法规条款 (§1512.5, §101(a)...)       │
│ Requirement      │ 法规要求 (50 条规则)                  │
│ ProductType      │ 产品类型 (Bicycle, Kids Bicycle...)  │
│ Component        │ 产品组件 (Brake, Reflector, Battery) │
│ TestMethod       │ 测试方法 (Overcharge, Road Test...)  │
│ Hazard           │ 危险类型 (Fire, Lead Poisoning...)   │
│ Consequence      │ 后果类型 (Recall, Fine, Delist...)   │
│ EvidenceType     │ 证据类型 (Test Report, BOM, Photo)   │
│ Standard         │ 引用标准 (ISO, ASTM, UL)             │
└──────────────────┴──────────────────────────────────────┘
```

### 5.3 推理引擎伪代码

```
FUNCTION analyze_compliance(product_profile):

    # Stage 1: Product Classification (已完成，product_profile 已输入)
    product_type = classify_product(product_profile)

    # Stage 2: Rule Matching
    applicable_rules = []
    FOR rule IN rule_store:
        IF product_type NOT IN rule.applicable_products:
            CONTINUE
        IF evaluate_conditions(rule.trigger_conditions, product_profile):
            applicable_rules.append(rule)

    # Stage 3: Evidence Checking
    evaluated_rules = []
    FOR rule IN applicable_rules:
        evidence_results = []
        FOR evidence_req IN rule.evidence_required:
            found = search_evidence(evidence_req, product_profile)
            evidence_results.append(found)

        status = determine_status(evidence_results)
        evaluated_rules.append({
            "rule": rule,
            "status": status,
            "evidence": evidence_results
        })

    # Stage 4: Risk Assessment
    total_risk = 0
    risk_items = []
    FOR evaluated IN evaluated_rules:
        IF evaluated.status != "MET":
            score = calculate_risk_score(evaluated.rule.risk_level, evaluated.status)
            total_risk += score
            risk_items.append(evaluated)

    overall_risk = total_risk / len(evaluated_rules)
    compliance_score = 100 - overall_risk

    # Stage 5: Report Generation
    report = generate_report(
        evaluated_rules,
        compliance_score,
        risk_items
    )

    RETURN report


FUNCTION evaluate_conditions(conditions, profile):
    FOR condition IN conditions:
        field_value = get_nested_field(profile, condition.field)
        result = compare(field_value, condition.operator, condition.value)
        IF NOT result:
            IF condition.logic == "AND":
                RETURN False
            ELSE:
                CONTINUE
    RETURN True


FUNCTION search_evidence(evidence_req, profile):
    SWITCH evidence_req.evidence_type:
        CASE "bom_component":
            RETURN profile.components contains evidence_req.description
        CASE "spec_sheet_value":
            RETURN get_nested_field(profile, evidence_req.source_path) exists
        CASE "test_report":
            RETURN profile.tests contains matching test_name AND result
        CASE "label_photo":
            RETURN profile.labels contains matching content
        CASE "manual_document":
            RETURN profile.documentation contains doc_type == "manual"
        CASE "certificate":
            RETURN profile.documentation contains doc_type == "CPC"
        DEFAULT:
            RETURN None


FUNCTION determine_status(evidence_results):
    IF all evidence found AND valid:
        RETURN "MET"
    ELIF some evidence found:
        RETURN "PARTIALLY_MET"
    ELIF no evidence found BUT documents don't cover this:
        RETURN "NOT_ASSESSED"
    ELSE:
        RETURN "NOT_MET"
```

### 5.5 推理引擎关键设计原则

| 原则 | 说明 |
|------|------|
| **确定性优先** | 规则匹配基于明确的条件表达式，不依赖 LLM 推理 |
| **可解释性** | 每条判定结果附带法规原文引用和证据来源 |
| **保守策略** | 证据不足时判定为 NOT_ASSESSED 而非 MET，避免假合规 |
| **规则可扩展** | 新法规规则只需添加 JSON 文件，无需修改引擎代码 |
| **条件组合** | trigger_conditions 支持 AND/OR 逻辑组合 |
| **产品类型继承** | E-bike 自动继承 Bicycle 的所有适用规则 |
| **豁免传递** | sidewalk bicycle 的豁免规则优先于通用规则 |
| **置信度分级** | HIGH/MEDIUM/LOW/NONE 四级证据置信度 |
